# 发布资源

- 仅从 `main` 发布，且待处理变更必须全部位于 `assets/`。
- `assets/` 必须是完整快照，并保留用户提供的目录结构。
- 时间分支不可变：不得复用、修改或强制推送已发布分支。
- 不得修改 `origin`，不得丢弃或夹带无关变更。

运行 `./scripts/publish-assets.sh`；只有用户明确给出分支名时才传入该名称，否则由脚本生成本地时间分支。成功后确认已切回干净的 `main` 并报告远程分支；失败时保留原时间分支和提交用于重试，不得创建重复快照或改写历史。
