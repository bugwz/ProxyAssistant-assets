# 发布资源

- 仅从 `main` 发布；使用临时 worktree，当前未提交的非发布变更不得进入发布分支或被清理。
- 普通模式将 `assets/` 当前内容作为完整快照发布；只有用户明确给出分支名时才传入名称，否则由脚本生成本地时间分支。
- 批量模式在 `assets/` 顶层存在一个或多个 `yyyyMMddHHmmss` 目录时启用；每个目录名是目标分支名，目录内容会成为对应分支的 `assets/` 内容，不保留外层时间目录。
- 批量模式只处理时间目录且不传入分支参数；`assets/` 顶层的其他文件和目录不发布、不清理并保持原状。
- 每个时间分支必须是独立的无父提交，分支根目录只能包含 `assets/`；不得包含 `main` 中的 README、LICENSE、代理规范、技能、脚本或其他文件。
- 时间分支不可变：不得复用、修改或强制推送已发布分支。
- 不得修改 `origin`，不得丢弃或夹带无关变更。

运行 `./scripts/publish-assets.sh`。脚本会先预检所有目标分支，再使用临时 worktree 创建只含 `assets/` 的独立分支并验证根目录；只有全部推送成功后才移除已发布的时间目录，其他 `assets/` 内容保持原状。成功后报告全部远程分支；失败时保留未清理的时间目录以及已创建的分支和提交，停止后续发布，不得创建重复快照或改写历史。
